# Solar Calculator

Uma calculadora moderna construída com **Next.js 14**, **TypeScript** e **Tailwind CSS** — pronta para deploy no Vercel.

## 🚀 Features

- ➕ Operações básicas: adição, subtração, multiplicação, divisão
- 🔢 Suporte a decimais
- ± Alternar sinal (positivo/negativo)
- % Cálculo de porcentagem
- 🔗 Encadeamento de operações
- 💅 Design escuro moderno e responsivo

## 🛠️ Tecnologias

- [Next.js 14](https://nextjs.org/) — App Router
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)

## ▶️ Rodando localmente

```bash
npm install
npm run dev
```

Acesse [http://localhost:3000](http://localhost:3000).

## 🌐 Deploy

Este projeto está configurado para deploy direto no [Vercel](https://vercel.com). Basta importar o repositório e fazer o deploy.
